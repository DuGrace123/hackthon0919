# 公开剪辑资料归纳与 4.13 规则映射

本次只读取公开页面、标题、简介、目录和开源文档，没有下载、复制或重新发布 B 站视频，也没有“训练基础模型”。

| 事件 | 画面处理 | 声音处理 | 字幕处理 | 密度约束 |
|---|---|---|---|---|
| 开场钩子 | 高级开篇模板 / 结果先露 | impact、滴答或 whoosh | 大字 Q 弹 / 镂空字 | 只在开头集中一次 |
| 章节或地点变化 | 慢推、淡黑或溶解 | riser 提前进入 | 重点高亮 | 与上次强强调至少 9 秒 |
| 动作峰值 | 冲击推近、smooth | whoosh 对齐动作 | 节奏滑动 | 连续动作普通切点不加 |
| 冲突 / 障碍 | 轻手持、撕裂 | bass drop | 印章 | 不连续使用撕裂 |
| 细节 / 美食 / 物件 | 慢推、圆形揭示 | bubble pop | 气泡弹出 | 每段只强调首个新信息 |
| 结果揭示 | 推近、闪白 | magic ding | Q 弹果冻 | 作为情绪峰值 |
| 结尾回收 | 慢推、溶解 | soft chime | 极简无底框 | 音乐 2 秒淡出 |

声音先建立节奏骨架：配乐根据类型选择；原声/对白存在时自动侧链压低背景音乐；音效只放在有叙事功能的事件上。真实拍摄顺序约束不变，创意规划器只修改表现字段，从不重排镜头。

研究入口：

- B站公开检索：剪辑节奏、声音转场、音乐分段、字幕动画、蒙版转场、画中画、撕纸转场。
- Remotion 官方文档：Transitions、SFX、Captions、Fonts。
- PySceneDetect 官方文档：场景边界检测。
- auto-editor 官方仓库：音频静音与节奏驱动的自动裁切思路。
- Google Fonts / 字体上游官方仓库：OFL 字体与许可。
