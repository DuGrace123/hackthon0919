# 网页端 AI 导演（2026-09-19，未发布）

## 已实现

- 产品界面收敛为网页编辑器 `web_app.py`；桌面版 `video_editor_app.py` 不再维护，仅保留在仓库中。
- 网页编辑器顶栏新增「AI 导演 / AI Director」：勾选素材、设定目标时长与剪辑要求，本地模式用 FFmpeg 场景检测选片且不上传素材，云端模式在服务端配置密钥并勾选同意后可用。
- 方案预览列出每个镜头的来源、入出点、字幕、理由和应用后的改动范围，点击镜头可在监视器中预览；应用后片段带「AI」标签并立即落盘，可一键撤销。
- 工程新增 `revision` 乐观锁：方案生成后若有手工编辑，应用返回 409，不覆盖未见过的修改；仅重复提交相同标题/画幅不会使方案失效。
- 片段编辑接受 AI 方案可能产生的全部转场，AI 片段可继续手工修改。
- FFmpeg 查找改为跨平台：`LINGJIAN_FFMPEG`、仅 Windows 使用仓库内 `ffmpeg.exe`、`PATH`、`imageio-ffmpeg`；新增 `requirements-web.txt`。
- 账户管理页新增「AI 接口」：管理员填写接口地址、API Key、视觉/转写模型与超时，可测试连接；配置保存在服务端并即时生效，优先于环境变量，密钥不回传浏览器。
- 登录页语言切换改为「中文 | EN」两段式开关；AI 导演面板在云端未配置时提示管理员前往配置。

## 质量保证

# 灵剪 AI 4.13 · 全片创意导演

## 已实现

- AI 不再只设计片头：为全片建立章节、动作、时间、冲突、细节、揭示、回收事件图。
- 强视听强调有最小间隔，普通因果切点保持干净，避免 120 秒视频后半段被随机特效淹没。
- 真实渲染三种镜头运动：慢推、冲击推近、轻手持；按语义自动匹配高级转场。
- 八种可编辑字幕动效：干净、Q 弹果冻、节奏滑动、逐字输入感、印章、气泡、重点高亮、极简。
- 三款可随安装包分发的开源中文字体：站酷快乐体、站酷庆科黄油体、霞鹜文楷。
- 音效库由 10 个扩至 16 个，新增章节蓄力、低频坠落、结果叮、气泡、柔和钟声、心跳。
- 六首本地原创循环音乐；AI 按旅行、美食、生活、剧情、纪录、口播风格自动选曲。
- 背景音乐具备开头/结尾淡化与对白侧链闪避，人物说话时自动压低音乐。
- 方案预览列出全片所有重点事件的时间、动效、字幕样式、音效和自动配乐，应用后仍可逐项人工修改。

## 质量保证

- DJI 真实素材全组合渲染连续 5 轮通过。
- 核心 85 项连续 5 轮通过。
- 101 片段 / 365.4 秒正文顺序修复连续 5 轮通过。
- 多轨合成、8 套创意开篇、16 音效混音旧功能回归全部通过。

## 媒体导入与导出可靠性（成员 2）

- 导入前统一校验路径、扩展名、大小与批次上限（可用 `LINGJIAN_MAX_FILE_BYTES` / `LINGJIAN_MAX_FILE_COUNT` / `LINGJIAN_MAX_TOTAL_BYTES` 覆盖），并用 FFmpeg 探测拒绝伪造扩展名、无视频流或时长无效的文件；重复路径不再产生重复素材或任务。
- 缩略图、代理与导出都先写入唯一临时文件，校验通过后原子替换；失败或取消只清理本次任务的半成品，不触碰旧缓存和用户已有文件。
- 导入、代理、导出均有可见进度与取消入口；取消会终止对应 FFmpeg 子进程并等待退出，程序关闭时不遗留后台进程。
- 新增 `media_tasks.py` 与 `tests/test_media_pipeline.py`（`python -m tests.test_media_pipeline [样例.mp4]`）。
